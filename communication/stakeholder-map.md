# Time Manager — Stakeholder Map

The Gotham town hall union fears the Time Manager app will make employees' lives more complex, and has pushed the mayor to address it directly. This map identifies who is affected by the app, how invested each group is, and what they need or worry about, so the mockups and the communication plan both target the right concerns.

## Stakeholder map

| Stakeholder | Commitment | Needs | Worries |
| --- | --- | --- | --- |
| Employees | Skeptical | Fast, simple clock-in/out; reassurance the tool isn't used against them | Feels like surveillance; one more complicated tool; penalized for honest mistakes |
| Union (CGT-U) | Opposed, vocal | Transparency; proof the tool protects workers, not just tracks them | Formalizes problems (long shifts, poor conditions) without fixing them; distrust of management's intent |
| Managers | Neutral | A clear team overview with minimal admin overhead | Tool adds work instead of saving it; unclear what they're accountable for |
| Administrator | Supportive | Accurate data for decisions; simple user administration | Data becomes unreliable if employees resist or misuse the tool |
| The mayor | Invested, under pressure | A visible, well-received result to show the union and the press | Public backlash; project seen as rushed or uncaring |
| Gotham citizens | Indirect, passive | Town hall services run smoothly (shorter queues, responsive staff) | Not usually vocal, but the underlying reason the project matters |
| Dev team | Invested | Buy-in so the app actually gets adopted | Rejection; building something nobody ends up using |

## How this feeds the rest of the mission

Each mockup answers one row above directly: the employee screen is a single clock button plus their own hours, countering the "one more complicated tool" worry; the manager screen flags overwork automatically so oversight doesn't cost extra effort; the administrator screen keeps user management to one click, protecting data integrity.

The same worries set the communication plan: the union and employees need a short, reassuring piece (a one-page leaflet or a short video showing the clock-in flow); the mayor needs a public-facing piece addressing the press and citizens.
